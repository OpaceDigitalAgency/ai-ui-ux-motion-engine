# Contributing to Opace Agent Skills

Contributions should improve a reproducible workflow, implementation pattern or validation gate.

1. Keep `SKILL.md` concise and route detail into `references/`.
2. Preserve framework neutrality and progressive enhancement.
3. Include reduced-motion, keyboard, touch and mobile behaviour with every interaction pattern.
4. Cite current official provider documentation for connector changes.
5. Add no credential, copied proprietary asset or unlicensed component.
6. Run the skill and plugin validators plus every affected script.
7. Describe what was tested and what remains unverified.

Do not add claims of guaranteed conversion, ranking, WCAG conformance, performance or visual continuity without direct evidence.

## Repository scope

This repository contains one canonical skill. Keep human-facing installation
and discovery content in the root README; do not add an auxiliary README or
installation guide inside `skills/ai-ui-ux-motion-engine/`.

Propose separate technical SEO, on-page SEO, content strategy, schema markup,
accessibility, analytics, conversion optimisation or digital-marketing skills
through the [Opace Agent Skills collection](https://github.com/OpaceDigitalAgency/skills).

For professional web design and development context, see
<https://opace.agency/services/web-design/>.
