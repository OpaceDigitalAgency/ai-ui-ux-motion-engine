## Search and trust checklist

1. Make the repository public.
2. Set the description and all 20 topics.
3. Keep the root `README.md`, `LICENSE`, `SECURITY.md` and
   `CONTRIBUTING.md`.
4. Create the `v1.6.1` release and attach the matching ZIP.
5. Keep the contextual Opace web-design link in the README and repository
   website field.
6. Submit or share useful examples rather than manufacturing keyword-heavy
   pages.
7. Keep official platform paths and compatibility claims current.

Repository settings should keep Issues, Discussions, Projects and Wiki enabled,
allow squash and rebase merges, automatically delete merged branches, require
web-based commit sign-off and keep the default branch named `main`.
