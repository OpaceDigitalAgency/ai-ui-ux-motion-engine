## Reference mashup

```text
Use $ai-ui-ux-motion-engine to combine these references without cloning.
Extract page rhythm from reference A and interaction language from reference B.
Keep all branding, copy, evidence, information architecture and assets native to this project.
Identify any element too identity-specific to reuse.
```

## Hero alternatives

```text
Use $ai-ui-ux-motion-engine to prepare exactly three hero directions.
Hold content, palette and target viewport constant.
Vary only composition and the signature interaction.
For each option state hierarchy, motion, reduced-motion equivalent, performance cost and implementation risk.
Do not change production files until a direction is selected.
```

## Motion audit

```text
Use $ai-ui-ux-motion-engine in audit-only mode.
Report motion purpose, input parity, reduced-motion behaviour, mobile fallback, performance risk and implementation defects.
Do not edit files.
```

## Prompt/reference-image product film

```text
Use $ai-ui-ux-motion-engine and the generated product scrubber workflow.

Create a watch-style, scroll-linked inspection of this product using approved
reference images and prompts, not CAD or a GLB model. First approve one clean
still and lock subject geometry, lens, camera path, lighting, background,
duration and end frame. Generate short silent clips, chain from exact final
frames where needed, reject geometry/text drift, then deliver the lightest
tested video or canvas scrubber.

Keep the offer, H1, actions, labels and evidence copy in semantic HTML. Provide
poster, reduced-motion, Save-Data, no-JavaScript and media-error fallbacks.
Validate protected crops, native scrolling, keyboard/touch use, mobile Safari,
desktop, console, performance and the full project baseline.
```

Use $ai-ui-ux-motion-engine for this bounded component only.
