# Bookshop to ecommerce homepage

Revision: 2
Status: agreed

## Confirmed requirements
Initial request: “Create a physical store that implodes into an ecommerce webpage using the motion skill.”
User clarification: “A bookshop. Elegant folding. The point is keeping the character of the physical shop while letting people browse and buy from anywhere. It will be a homepage scroll experience.”

The project is a fictional independent shop with static HTML. All work stays local; no external services, paid generation, dependency installation, repository operations or deployment. Actual payment processing is outside this local scope.

## Proposed complete experience
Audience: readers who value an independent bookshop's selection and personal recommendations. The homepage should make them feel invited into the same shop online and lead naturally into browsing and a demonstrable basket.

Opening: a warm, miniature bookshop seen through an open frontage, with timber shelves, books displayed face-out, a recommendation table and a recognisable shop sign. Paper cream, ink brown and muted burgundy pair with literary serif headings and restrained interface type. This is a deliberately illustrated fictional shop, with illustrative books and staff recommendations rather than claims about a real business.

Progression: visitor scrolling gently brings the viewpoint closer. The side walls hinge inward like a book cover; shelves rotate and settle into flat rows; the recommendation table becomes a staff-picks collection. Keep individual book covers visible throughout to demonstrate continuity. Motion is calm, coordinated and reversible with scrolling.

Signature moment: the shop's folded planes align with the screen and become the actual ecommerce layout. The physical sign takes its place as the masthead; face-out books finish as usable product cards; handwritten recommendation details remain beside their books. The till becomes the basket control. No explosive debris or unrelated replacement page.

Destination: the same warm bookshop identity, now a legible homepage with browseable books, staff picks and local demonstration basket interactions. Proposed headline: “Your favourite corner of the world. Wherever you are.” Fictional branding and original illustrative book covers are agent proposals, not supplied assets. Buying from anywhere is the message; actual checkout needs a later commerce integration.

Interaction and access: one homepage scroll sequence, with an obvious way to skip straight to books and no forced timed viewing. Mobile keeps the same sequence in a simpler, readable composition. Reduced-motion visitors receive the settled shop homepage without moving folds. Controls remain keyboard usable and book information stays readable.

Observable success: the shop's books and distinctive fixtures remain recognisable as they take on digital roles, the folded scene resolves cleanly into an usable catalogue, and visitors can immediately browse and add a book to a demo basket on desktop and mobile. Failure includes generic particles, unreadable moving covers, a transformation that drops the shop's character, or an attractive finale that cannot be used.

## Agreement
User agreed revision 2: “Yes, that complete bookshop brief captures what I want. Go on then and build the private local proof.”

## Production status
Selected route: local authored DOM/CSS layers, illustrative flagship with stable fictional book identities. No provider, spend or external assets. Existing index.html contains only an Independent shop heading; no functional baseline or test runner exists. First bounded pass: isolated folding proof, leaving index.html intact. Acceptance will require visible correspondence of the same books, shelves, sign and till into catalogue roles, reversible scroll, desktop and 375px checks, keyboard and reduced-motion checks. Browser and regression checks remain pending; current handoff stops after the first implementation file change.
